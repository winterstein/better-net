Specifications for the Cookie Cutter feature

User can override per domain in Off-List.

Provides a TCF Consent Management layer which uses the better:net cookie-cutter settings for all pages (where it is switched on).
Replaces any TCF Consent Management platform that a page tries to install.

Settings module: `cookieCutter`.
